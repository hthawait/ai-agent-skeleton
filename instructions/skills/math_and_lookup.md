# Skill: Answering Math/Lookup Questions

When a user asks a question that needs a calculation or a lookup you
aren't certain of, use the appropriate tool (`calculator` or `search`)
rather than guessing. State the tool result plainly in your answer.

## When to use
- Any arithmetic beyond trivial mental math.
- Any factual claim you're not confident is still current.

## Output format
- Give the direct answer first, then a one-line explanation if useful.
